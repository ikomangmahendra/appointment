# Jam Operasional conflict check aggregates across every Dokter, not one at a time

Jam Operasional is Klinik-wide, so editing it can shrink the effective window for every Dokter at once — unlike a Jadwal or Pengecualian Jadwal edit, which only ever affects one Dokter. Rather than reusing the single-Dokter conflict-review pattern from [ADR 0018](0018-jadwal-conflict-flags-appointment-for-reschedule.md) once per affected Dokter, a Jam Operasional edit's conflict check aggregates every affected Appointment across all of the Klinik's Dokter into one review screen, so the admin sees the full blast radius before deciding to force it through with one reason (or cancel). The block-outright rule for any Patient who has already arrived, from ADR 0018, still applies the same way, just checked across the whole set instead of one Dokter's.
