Admin Klinik: Membuat Jadwal Dokter

Logic prototype — satu file HTML, tanpa server, tanpa database.
Pertanyaan yang dijawab prototype ini: Saat Admin Klinik mengatur Jadwal rutin seorang Dokter, menambah Pengecualian Jadwal (cuti / jam khusus), atau mengubah Jam Operasional klinik — apakah model data Jadwal + Pengecualian Jadwal + Jam Operasional → Slot dari CONTEXT.md benar‑benar tahan terhadap kasus sulit? Terutama: apa yang terjadi pada Appointment yang sudah dikonfirmasi pasien saat perubahan jadwal membuat slot itu tidak lagi tersedia? Apakah sistem boleh mendiam‑diam “menghilangkan” appointment itu, atau harus memblokir perubahan sampai admin sadar dan memutuskan?

Asumsi: tidak ada halaman Angular/Spring yang sudah berjalan untuk fitur ini, jadi ini prototype logic (bukan UI) — pertanyaan yang diuji adalah model state, bukan tampilan.
